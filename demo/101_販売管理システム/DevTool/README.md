# DevTool

デモ101に特化した編集ツール。

利用者は実際にデモ101アプリを見て、画面やデータベース定義を確認しながら
AIエージェントに指示を出し、エージェントは裏側で Nijo を駆使しつつ
アプリケーションを改修していく。

プログラミングの素養がない利用者が独力で仕様を固めていけるようにすることを目指している。

## セットアップ

リポジトリルートで依存関係をインストールしていない場合は先に実行する。

```sh
npm install
```

下記手順で起動し、起動後の設定画面で OpenRouter APIキーを登録する。APIキーはOSのキーチェーンに保存され、`.env.local` やリポジトリには保存されない。
（以前 Anthropic APIキーを登録していた場合はキーチェーンの保存先が別になるため、OpenRouterのキーを登録し直す必要がある）

## 起動

このフォルダで以下を実行すると、クライアント（vite）とサーバー（Node）が同時に起動する。

```sh
npm run dev
```

型検査だけやる場合はこちら

```sh
npm run tsc    # 型検査（client/server/node の3プロジェクト）
npm run build  # 型検査 + クライアントのビルド
```

サーバー単体が正しく起動しているかは、以下で確認できる。

```sh
curl http://127.0.0.1:5184/devtool-api/settings
```

ポート5184が既に使用されている場合、サーバーのコンソールにエラーが出力される。他に起動しているプロセスがないか確認すること。
