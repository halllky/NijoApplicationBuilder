# DevTool デバッグ手順

## 起動

リポジトリルートで依存関係をインストールしていない場合は先に実行する。

```sh
npm install
```

このフォルダで以下を実行すると、クライアント（vite, ポート5177）とサーバー（Node, ポート5184）が同時に起動する。

```sh
npm run dev
```

ブラウザで http://localhost:5177 を開く。デバッグ対象アプリ（`client` / `WebApi`）はツールバーの「開始」ボタンから起動できる。

クライアント・サーバーを個別に起動したい場合は `npm run dev:client` / `npm run dev:server` を使う。

## エージェント機能を使う場合

ツールバー右端の歯車アイコンから設定画面を開き、Anthropic APIキーを登録する。APIキーはOSのキーチェーンに保存され、`.env.local` やリポジトリには保存されない。

チャット・コーディング両エージェントのモデル設定は `.env.local`（このフォルダ直下、gitignore対象）に保存される。

## 動作確認

```sh
npm run tsc    # 型検査（client/server/node の3プロジェクト）
npm run build  # 型検査 + クライアントのビルド
```

## ポート・API疎通確認

サーバー単体が正しく起動しているかは、以下で確認できる。

```sh
curl http://127.0.0.1:5184/devtool-api/settings
```

ポート5184が既に使用されている場合、サーバーのコンソールにエラーが出力される。他に起動しているプロセスがないか確認すること。
